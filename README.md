# 🌕 LunarBase: Junior Astronaut Mission Trainer

**Could you keep your crew alive on the Moon?**

LunarBase is a 3D interactive educational game developed for the **NASA Space Apps Challenge 2026**. Players take command of a simulated lunar base and must keep their crew alive for five days while managing limited resources, responding to radiation alerts, and handling unexpected equipment failures.

The goal is to make the challenges of lunar exploration more engaging and understandable through interactive gameplay.

![LunarBase Gameplay](demo pic.png)

## 🚀 Project Overview

Living on the Moon would require careful planning, resource management, and the ability to respond to unexpected situations.

In LunarBase, players experience some of these challenges by taking the role of a lunar base commander. Every decision can affect the crew's survival.

## 🎮 Gameplay Features

- **Five-Day Mission:** Lead a simulated lunar mission and keep the crew alive.
- **Resource Management:** Monitor essential resources such as oxygen, water, food, and electricity.
- **Radiation Alerts:** Respond to simulated space-weather and radiation-related events.
- **Equipment Failures:** Handle unexpected system problems.
- **Decision-Making:** Make choices that influence mission conditions and crew survival.
- **Science Behind the Game:** Explore NASA resources connected to space weather and radiation research.

## 🛰️ NASA Data and Resources

The project draws on NASA resources to connect the gameplay with real space science.

### 1. NASA DONKI – Space Weather Database

NASA's Database of Notifications, Knowledge, Information (DONKI) provides space-weather event information.

Resource: https://ccmc.gsfc.nasa.gov/tools/DONKI/

### 2. NASA OSDR RadLab – Radiation Data

NASA's Open Science Data Repository (OSDR) RadLab provides access to radiation measurements from spaceflight research.

Resource: https://visualization.osdr.nasa.gov/radlab/gui/data-api/

These resources provide scientific context for the educational experience. The game's mission conditions and events are simulated and should not be interpreted as real-time lunar forecasts or actual lunar surface measurements.

## 🛠️ Development

The project was developed using **Google AI Studio Build mode** with AI-assisted development.

The development process involved:
- Turning a space-exploration challenge into an interactive game concept.
- Designing gameplay around resource management and mission decisions.
- Exploring NASA space-weather and radiation resources.
- Building and refining an interactive user experience.

LunarBase is an educational simulation. It is not an operational lunar mission system, a scientific radiation prediction tool, or a substitute for actual NASA mission data and safety systems.
